# Security Policy

> This project is in early development (`v0.1.0`, Foundation stage). This policy will expand as the product surface grows — see [Roadmap](./docs/roadmap.md).

## Reporting a Vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, report privately via GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature on this repository.

Include, if possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- Any suggested mitigation

We'll acknowledge reports as soon as possible and follow up as the issue is triaged. Please allow time to address a report before any public disclosure.

## Supported Versions

v0.1.0 — only the latest released version is supported.
